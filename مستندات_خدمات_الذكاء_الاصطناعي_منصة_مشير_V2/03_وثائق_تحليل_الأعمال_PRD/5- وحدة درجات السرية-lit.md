## **وحدة درجات السرية – نظام إدارة التقاضي**

### **1\. الغلاف**

* **اسم الوحدة:** درجات السرية  
* **الجهة:** المكتب الفني – ديوان المظالم  
* **عنوان الوثيقة:** تحليل متطلبات وحدة درجات السرية في نظام إدارة القضايا  
* **التاريخ السابق:** 06-08-2025  
* **الإصدار السابق:** 0.1 – مبدئي  
* **التاريخ الجديد:** 09-09-2025  
* **الإصدار الجديد:** 0.2 – نهائي

### **2\. المقدمة**

تغطي هذه الوثيقة متطلبات وحدة "درجات السرية"، وهي مكوّن تنظيمي يتيح ضبط صلاحيات الاطلاع على مكونات القضايا داخل نظام إدارة التقاضي، بما يضمن الحفاظ على خصوصية المعلومات، حماية المخرجات الرسمية، والالتزام بالإجراءات المؤسسية.

تُطبق درجات السرية على مستوى القضية أو على مستوى كل مكون فرعي داخلها (مثل المذكرة، المحاضر، التقارير، المرفقات...)، وتُستخدم لضبط ما يمكن للمستخدم الاطلاع عليه حسب دوره ومشاركته في القضية، مع توثيق كل عملية إفصاح أو تقييد.

### **3\. الأهداف**

1. ضبط مستوى الوصول إلى المعلومات الحساسة داخل القضية.  
2. حماية المكونات الرسمية من التعديل أو العرض غير المصرّح.  
3. تطبيق سياسة “الاطلاع حسب الحاجة” داخل فرق العمل.  
4. تمكين المشرف على الإدارة من تحديد من يرى ماذا، ومتى.  
5. دعم إجراءات الأرشفة وفق درجة السرية المعتمدة.  
6. ربط الصلاحيات الإجرائية بدرجة السرية تلقائيًا.

### **4\. الأدوار والصلاحيات**

| الدور | الوصف | الصلاحيات |
| ----: | ----: | ----: |
| المشرف على الإدارة | الجهة الوحيدة المخوّلة بتحديد درجات السرية وتفويض الاطلاع | تعيين – تعديل – رفع السرية – تقييد الوصول |
| أعضاء فريق القضية | يمكنهم الاطلاع الكامل على جميع مكونات القضية دون قيود | افتراضيًا، حتى مع وجود سرية |
| مستخدمون خارج فريق القضية | لا يمكنهم الاطلاع إلا إذا منحهم المشرف صلاحية استثنائية | عرض فقط – بدون تعديل أو نقل |
| النظام | يطبّق سياسة السرية تلقائيًا حسب الإعدادات | حجب – إظهار – تسجيل محاولات الوصول |

### **5\. المتطلبات الوظيفية (Functional Requirements)**

**أولًا: إدارة درجات السرية على مستوى القضية**

| الكود | المتطلب |
| ----: | ----: |
| F-1.1 | إمكانية تصنيف كل قضية بدرجة سرية (حسب درجات السرية المعتمدة من الديوان ومسجلة بالنظام) |
| F-1.2 | تطبيق الدرجة افتراضيًا على جميع المكونات داخلها |
| F-1.3 | إمكانية تعديل درجة السرية أثناء سير القضية إذا لزم |

**ثانيًا: إدارة السرية على مستوى المكونات الفرعية**

| الكود | المتطلب |
| ----: | ----: |
| F-2.1 | إمكانية إعطاء درجة سرية مختلفة لكل مكوّن (مذكرة، محضر، مرفق...) |
| F-2.2 | وراثة الدرجة من القضية ما لم يتم تعديلها يدويًا |
| F-2.3 | منع العرض أو التعديل بناءً على الدرجة ما لم يُفوض المستخدم |

**ثالثًا: صلاحيات الاطلاع**

| الكود | المتطلب |
| ----: | ----: |
| F-3.1 | الفريق المعين في القضية يمتلك صلاحية الاطلاع الكاملة بغض النظر عن السرية |
| F-3.2 | المستخدمون من خارج الفريق لا يرون المكون إلا إذا فُوّضوا صراحة |
| F-3.3 | كل تفويض يُسجل في سجل الإفصاح بشكل رسمي |

**رابعًا: سجل الإفصاح والتحكم**

| الكود | المتطلب |
| ----: | ----: |
| F-4.1 | سجل زمني لكل عملية تغيير في درجة السرية أو تفويض اطلاع |
| F-4.2 | سجل محاولة الوصول غير المصرّح لأي مكون |
| F-4.3 | دعم تصدير سجل السرية للجهات المختصة أو الإدارة العليا |

### **6\. المتطلبات غير الوظيفية (Non-Functional Requirements)**

| الكود | المتطلب |
| ----: | ----: |
| NFR-1 | لا يُمكن تعديل المكونات ذات السرية العالية إلا من الفريق الأصلي أو المشرف |
| NFR-2 | الحماية تطبّق حتى على مستوى واجهة المستخدم (عدم ظهور المكون أصلًا أو اتاحة طلب الاطلاع حسب الاعدادات العامة للنظام) |
| NFR-3 | التكامل مع الأرشفة بحيث لا يُسمح بإخراج المكون إلا حسب درجته |
| NFR-4 | سجل تدقيق كامل للمكونات المصنفة وتغييرات السرية عليها |

### **7.بعض حالات الاستخدام (Use Cases)**

**UC-1: تصنيف قضية بدرجة “سري جدا”**

* المستخدم: المشرف على الإدارة  
* النتيجة: تُقيد كل مكونات القضية تلقائيًا وتُمنع الرؤية لغير الفريق أو لمن لهم تصريح أقل درجة

**UC-2: تفويض عضو من خارج الفريق للاطلاع على مذكرة**

* المستخدم: المشرف على الإدارة  
* النتيجة: يظهر له المكون المحدد فقط دون بقية أجزاء القضية

**UC-3: تعديل درجة السرية لمرفق معين داخل القضية**

* المستخدم: المشرف على الإدارة  
* النتيجة: المرفق يُصبح مقيدًا حتى على بعض أعضاء الفريق غير المفوضين

### **8\. القيود والافتراضات**

**القيود:**

* لا يمكن للمستخدمين خارج الفريق تعديل أو مشاهدة المكونات السرية إلا بتفويض رسمي.  
* لا يمكن تخفيض درجة السرية إلا من قبل المشرف على الإدارة.

**الافتراضات:**

* كل مكوّن يرث الدرجة تلقائيًا من قضيته ما لم يُحدد خلاف ذلك.  
* النظام يحجب كل الحقول والمرفقات تلقائيًا عند تفعيل السرية.
