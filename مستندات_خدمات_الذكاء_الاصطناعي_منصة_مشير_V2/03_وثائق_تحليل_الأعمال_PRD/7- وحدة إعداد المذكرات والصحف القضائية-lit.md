## **وحدة إعداد المذكرات والصحف القضائية – نظام إدارة التقاضي**

### **1\. الغلاف**

* **اسم الوحدة:** إعداد المذكرات والصحف القضائية  
* **الجهة:** المكتب الفني – ديوان المظالم  
* **عنوان الوثيقة:** تحليل متطلبات وحدة إعداد المذكرات والصحف القضائية  
* **التاريخ السابق:** 06-08-2025  
* **الإصدار السابق:** 0.1 – مبدئي  
* **التاريخ الجديد:** 09-09-2025  
* **الإصدار الجديد:** 0.2 – نهائي

### **2\. المقدمة**

توثق هذه الوثيقة متطلبات وحدة إعداد المذكرات والصحف داخل نظام التقاضي، وهي المسؤولة عن إدارة دورة العمل الكاملة لإعداد، مراجعة، اعتماد، وتقديم المذكرات القانونية والصحف القضائية (صحف الدعوى، الاعتراض، المذكرات الجوابية، الختامية...) بشكل رسمي ومتسلسل.

تُستخدم الوحدة بشكل محوري داخل كل قضية، وتتكامل مع التواريخ النظامية، نظام الجلسات، المشاركين في القضية، وتدعم إخراج المستندات القضائية بصيغ متعددة.

### **3\. الأهداف**

1. تنظيم دورة إعداد جميع المذكرات والصحف القضائية.  
2. دعم التعاون بين الدارس والمشاركين والمعتمد ضمن نفس المذكرة.  
3. حفظ جميع الإصدارات وسجل التعديلات لكل مذكرة.  
4. ضمان الاعتماد الرسمي قبل التقديم القضائي.  
5. دعم مذكرات داخلية موجهة لرئيس المكتب أو جهات داخلية.  
6. إخراج المستندات بصيغ جاهزة للتقديم (PDF، Word...) حسب الجهة المستهدفة.

### **4\. الأدوار والصلاحيات**

| الدور | الوصف | الصلاحيات |
| ----: | ----: | ----: |
| الدارس | المسؤول الأساسي عن إعداد المذكرة | إنشاء – تحرير – تمرير – مراجعة \- إرفاق مستندات |
| المشاركون | يدعمون الدارس في إعداد المحتوى | تعديل \- تحرير جزئي – إرفاق ملاحظات – اقتراح تعديلات \- إرفاق مستندات |
| المعتمد | يراجع ويعتمد المذكرة قبل التقديم | تعديل \- اعتماد – طلب تعديل – رفض \- إرفاق مستندات |
| رئيس المكتب (عند الحاجة) | يُرسل له المذكرات الداخلية الخاصة | اطلاع فقط أو اعتماد نهائي \- إرفاق مستندات |
| الممثل | يقدّم المذكرة للمحكمة بعد اعتمادها | تصدير – تقديم – تسجيل الحالة \- إرفاق مستندات |
| النظام | يسجل التعديلات ويولد الإصدارات | إدارة السجل الزمني والمرفقات |

### **5\. المتطلبات الوظيفية (Functional Requirements)**

**أولًا: إعداد المذكرة أو الصحيفة**

| الكود | المتطلب |
| ----: | ----: |
| F-1.1 | فتح مسودة مذكرة مرتبطة بالقضية الجارية |
| F-1.2 | اختيار نوع المذكرة من قائمة (دعوى، رد، اعتراض، ختامية...) |
| F-1.3 | تخصيص النموذج المناسب حسب الجهة القضائية المستهدفة |

**ثانيًا: التعاون والتحرير**

| الكود | المتطلب |
| ----: | ----: |
| F-2.1 | تمكين الدارس والمشاركين من تحرير نفس المذكرة بتسلسل محفوظ |
| F-2.2 | دعم الملاحظات والتعليقات داخل النص |
| F-2.3 | منع التعديل من غير الفريق المعتمد للمذكرة |

**ثالثًا: الاعتماد والإصدارات**

| الكود | المتطلب |
| ----: | ----: |
| F-3.1 | تمرير المذكرة للمعتمد للمراجعة |
| F-3.2 | دعم اعتماد المذكرة أو إرجاعها بتعديل محدد |
| F-3.3 | حفظ سجل الإصدارات مع مقارنة بين كل إصدار |

**رابعًا: التقديم القضائي**

| الكود | المتطلب |
| ----: | ----: |
| F-4.1 | تصدير المذكرة بصيغة PDF أو Word حسب الجهة القضائية |
| F-4.2 | دعم إخراج المذكرة بتنسيقات متعددة (مفصّلة / مختصرة) |
| F-4.3 | تسجيل تاريخ التقديم والمرفقات المرافقة |

**خامسًا: المذكرات الداخلية**

| الكود | المتطلب |
| ----: | ----: |
| F-5.1 | دعم إعداد مذكرات داخلية موجهة لرئيس المكتب أو الإدارة |
| F-5.2 | نفس آلية التحرير والاعتماد دون تقديم قضائي خارجي |
| F-5.3 | تسجيل الغرض الإداري للمذكرة (طلب رأي – إحاطة – رد داخلي...) |

### **6\. المتطلبات غير الوظيفية (Non-Functional Requirements)**

| الكود | المتطلب |
| ----: | ----: |
| NFR-1 | واجهة مخصصة للتحرير تدعم اللغة العربية والملاحظات التفاعلية |
| NFR-2 | حفظ تلقائي للمسودة كل دقيقة |
| NFR-3 | دعم الإخراج النهائي بما يتوافق مع منصات “معين” و”ناجز” و "تنفيذ" |
| NFR-4 | حماية المحتوى أثناء التحرير – لا يُتاح لمن هم خارج الفريق |

### **7\. بعض حالات الاستخدام (Use Cases)**

**UC-1: إعداد مذكرة رد على مذكرة خصم**

* المستخدم: دارس  
* الخطوات: فتح مسودة → تحرير بالتعاون مع المشاركين → تمرير للاعتماد  
* النتيجة: مذكرة معتمدة جاهزة للتقديم

**UC-2: إعداد صحيفة دعوى جديدة**

* المستخدم: دارس  
* الخطوات: اختيار النوع → تحرير → مراجعة المعتمد  
* النتيجة: صحيفة دعوى معتمدة وجاهزة للتقديم عبر الممثل

**UC-3: إعداد مذكرة داخلية**

* المستخدم: دارس  
* الخطوات: اختيار الغرض الداخلي → كتابة المذكرة → تمريرها  
* النتيجة: مذكرة داخلية تُعرض على رئيس المكتب

### **8\. القيود والافتراضات**

**القيود:**

* لا يمكن تقديم مذكرة إلا بعد اعتمادها.  
* لا يُسمح بحذف أي إصدار بعد اعتماده.

**الافتراضات:**

* لكل نوع مذكرة نموذج مخصص داخل النظام.  
* النظام يربط تلقائيًا بين المذكرة وموعد الجلسة أو الإجراء القضائي.
