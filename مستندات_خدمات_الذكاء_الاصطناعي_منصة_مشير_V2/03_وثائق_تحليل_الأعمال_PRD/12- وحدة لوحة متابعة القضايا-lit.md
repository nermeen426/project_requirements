## **وحدة لوحة متابعة القضايا – نظام إدارة التقاضي**

### **1\. الغلاف**

* **اسم الوحدة:** لوحة متابعة القضايا  
* **الجهة:** المكتب الفني – ديوان المظالم  
* **عنوان الوثيقة:** تحليل متطلبات وحدة لوحة متابعة القضايا  
* **التاريخ السابق:** 06-08-2025  
* **الإصدار السابق:** 0.1 – مبدئي  
* **التاريخ الجديد:** 09-09-2025  
* **الإصدار الجديد:** 0.2 – نهائي

### **2\. المقدمة**

توفر هذه الوثيقة تحليلًا لوحدة لوحة متابعة القضايا، وهي واجهة مخصصة لكل مستخدم داخل النظام لعرض جميع القضايا والمهام المرتبطة به، بالإضافة إلى المؤشرات الزمنية، التنبيهات، والحالة العامة لكل قضية.  
 تُعد هذه اللوحة أداة تشغيلية تساعد كل عضو في معرفة ما هو مطلوب منه حاليًا، ومتى، وكيفية الوصول إلى المعلومات والمخرجات الخاصة به.

### **3\. الأهداف**

1. تمكين كل مستخدم من متابعة القضايا والمهام المرتبطة به فقط.  
2. عرض تنبيهات فورية عن الجلسات، المذكرات، الردود، والمهل النظامية.  
3. دعم اتخاذ القرار اليومي من خلال مؤشرات الأداء والفرز حسب الأولوية.  
4. توفير لوحة مركزية لمشرف الإدارة لرؤية المهام على مستوى الفريق.  
5. تسهيل الوصول السريع إلى المكونات النشطة داخل القضية.  
6. تقديم نظرة تحليلية لحالة القضايا وأداء الفريق.

### **4\. الأدوار والصلاحيات**

| الدور | الوصف | الصلاحيات |
| ----: | ----: | ----: |
| عضو الفريق (دارس – ممثل – معتمد...) | يرى قضاياه ومهامه فقط | تصفح – تنفيذ المهام – الإشعارات |
| مشرف الإدارة وسكرتير الإدارة | يرى جميع المهام لفريق الإدارة | تصفح شامل – مراقبة الأداء |
| رئيس المكتب | يرى جميع القضايا | تصفح شامل – مراقبة الأداء |
| النظام | يُولد البيانات تلقائيًا حسب الدور | تحديث مستمر للحالة والمؤشرات |

### **5\. المتطلبات الوظيفية (Functional Requirements)**

**أولًا: عرض القضايا حسب الدور**

| الكود | المتطلب |
| ----: | ----: |
| F-1.1 | عرض قائمة القضايا المرتبطة بالمستخدم فقط |
| F-1.2 | تمييز القضايا النشطة، المنجزة، المؤرشفة |
| F-1.3 | عرض دور المستخدم داخل كل قضية (دارس، مشارك، ممثل...) |

**ثانيًا: عرض المهام المطلوبة**

| الكود | المتطلب |
| ----: | ----: |
| F-2.1 | عرض المهام اليومية المعلقة لكل مستخدم حسب نوعها |
| F-2.2 | تحديد تاريخ الاستحقاق، حالة التنفيذ، المؤشرات الزمنية |
| F-2.3 | دعم التنقل السريع إلى المذكرة أو المشاركة أو الجلسة مباشرة من اللوحة |

**ثالثًا: المؤشرات والتنبيهات**

| الكود | المتطلب |
| ----: | ----: |
| F-3.1 | عرض مؤشرات مثل (عدد المهام النشطة – نسبة الإنجاز – تأخيرات حالية) |
| F-3.2 | عرض إشعارات مخصصة للمستخدم حسب نوع القضية |
| F-3.3 | دعم إبراز المهام الحرجة أو المتأخرة بلون مختلف |

**رابعًا: التخصيص والتصفية**

| الكود | المتطلب |
| ----: | ----: |
| F-4.1 | فرز القضايا حسب الأولوية، التاريخ، النوع، الحالة مع إمكانية الفرز بحسب تطلُّب القضية لأداء مهمة أو عدم تطلُّبها إلا للانتظار. |
| F-4.2 | تخصيص الأعمدة الظاهرة للمستخدم (حسب التفضيلات) |
| F-4.3 | حفظ إعدادات العرض لكل مستخدم على حدة |

**خامسًا: لوحة المدير**

| الكود | المتطلب |
| ----: | ----: |
| F-5.1 | عرض شامل لجميع القضايا الجارية داخل الإدارة |
| F-5.2 | فرز حسب العضو – نوع القضية – مدى التقدم |
| F-5.3 | مؤشرات أداء إجمالية لكل عضو (مهام منجزة – متأخرة – جاري تنفيذها) |

| الكود | المتطلب |

| NFR-3 | تجربة مستخدم سلسة على جميع الشاشات |
| NFR-4 | حماية المعلومات حسب صلاحية الدور |

### **7\. بعض حالات الاستخدام (Use Cases)**

**UC-1: مستخدم يتابع مهامه اليومية**

* المستخدم: دارس  
* النتيجة: يرى المهام المطلوبة منه اليوم، وتواريخ الاستحقاق،والقضايا المرتبطة

**UC-2: مشرف يتابع أداء الفريق**

* المستخدم: مشرف إدارة التقاضي   
* النتيجة: يرى مؤشرات الإنجاز ومهام كل عضو بالتفصيل

**UC-3: ممثل يستعد لجلسة**

* المستخدم: ممثل قانوني  
* النتيجة: يرى الجلسات القادمة ومذكرات الخصم المتعلقة بها

### **8\. القيود والافتراضات**

**القيود:**

* لا يمكن تنفيذ أي إجراء مباشر من اللوحة (تنفيذ المهام يتم من داخل كل مكون).  
* لا يمكن رؤية قضايا لا يشارك فيها المستخدم.

**الافتراضات:**

* كل مستخدم مقيّد بدوره وصلاحياته داخل النظام.  
* يتم تحديث البيانات لحظيًا بناءً على النظام المركزي.
