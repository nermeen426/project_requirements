# 📂 المرجع الموحد والوحيد للخدمة الثالثة (إصدار V2): مراجعة نحوية وإملائية ذكية (Smart Proofreading & Linguistic Review)

## 1. الوصف ونطاق الذكاء الاصطناعي المحدد حصراً (Excel Bounded AI Scope)

> [!IMPORTANT]
> **النطاق المحدد حصراً بموجب ملف الخدمات المحدث V2 (سطر 3):**
> * **الوصف المعتمد:** المراجعة والتدقيق النحوي والإملائي التلقائي لمسودات الصحف والمذكرات والتقارير القانونية لتصحيح الأخطاء اللغوية.
> * **التصنيف:** مراجعة | **الإدارة:** تقاضي | **الجهد التقديري:** 2 يوم عمل.
> * **ملاحظة مكتب الذكاء الاصطناعي:** الاشتراك مع مكتب الذكاء للتنسيق مع معايير مجمع الملك سلمان الدولي للغة العربية.

* **نطاق المعالجة المباشرة (In Scope):**
  1. **التدقيق النحوي والإملائي لكافة مسودات التقاضي:** اكتشاف وتصويب الأخطاء اللغوية والنحوية والإملائية بمسودات (صحف الدعاوى، مذكرات الرد، التقارير).
  2. **تطبيق معايير مجمع الملك سلمان:** التنسيق والتطبيق الآلي لقواعد الرسم الإملائي العربي المعتمد بمجمع الملك سلمان الدولي للغة العربية.
  3. **عرض التغييرات التفاعلي:** إظهار التعديلات والمقترحات عبر شاشة المقارنة الجانبية المباشرة (`Side-by-Side Diff View`).
* **حدود واستثناءات النطاق (Out of Scope):** 
  * يُستثنى صراحة التعديل على الوقائع والأحكام الموضوعية أو الأسانيد النظامية.
  * يُستثنى توليد مسودات جديدة (مخصص للخدمة 1) أو الاستخلاص المستندي (مخصص للخدمة 2) أو التصنيف الموضوعي (مخصص للخدمة 5).

## 3. قواعد العمل التشغيلية واللغوية (Extracted Business Rules)

1. **قاعدة سلامة المعنى القضائي:** حظر تعديل المصطلحات النظامية المعتمدة (مثل "الدائرة الرقمية"، "تظلم وظيفي"، "طلب عارض") أو استبدالها بألفاظ عامية.
2. **قاعدة التوافق مع معايير مجمع الملك سلمان:** ضبط همزات القطع والوصل، التاء المربوطة والهاء، والتنوين وفق ضوابط مجمع الملك سلمان.
3. **قاعدة العرض المزدوج (Diff View):** تسليط الضوء على الأخطاء اللغوية بلون واضح وإتاحة قبول أو رفض التعديل فردياً قبل الانعكاس بمحرر النصوص.

```json
{
  "case_id": "LIT-XXXX-XXXX",
  "confidentiality_level": "RESTRICTED",
  "proofread_request": {
    "document_type": "STATEMENT_OF_CLAIM",
    "raw_text": "[نص المسودة المراد تدقيقه لغوياً ونحوياً]"
  },
  "user_context": {
    "user_id": "USR-XXXX",
    "role": "LEGAL_EDITOR"
  }
}
```

```json
{
  "proofread_id": "PRF-XXXX-001",

    {
      "original_segment": "[الكلمة الإملائية الخاطئة]",

      "rule_ref": "معيار مجمع الملك سلمان الدولي - رسم الهمزة"
```
