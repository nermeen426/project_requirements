---

## 1. الوصف ونطاق الذكاء الاصطناعي المحدد حصراً (Excel Bounded AI Scope)

> [!IMPORTANT]
> **النطاق المحدد حصراً بموجب ملف الخدمات المحدث V2 (سطر 4):**
> * **الوصف المعتمد:** الاستخراج والترميز التلقائي للكلمات المفتاحية والمصطلحات القانونية الجوهرية من ملف القضية لدعم البحث والربط الموضوعي.
> * **التصنيف:** تحليل | **الإدارة:** تقاضي | **الجهد التقديري:** 2 يوم عمل.
> * **ملاحظة مكتب الذكاء الاصطناعي:** مشاركة الكلمات المفتاحية.

* **نطاق المعالجة المباشرة (In Scope):**
  1. **الاستخراج والترميز التلقائي للكلمات الجوهرية:** التعرف الآلي واستخلاص الوسوم (Tags) والمصطلحات الإجرائية والموضوعية من نصوص القضية.
  2. **دعم البحث والربط الموضوعي:** تكشيف الكلمات المستخرجة لتغذية محرك البحث المركزي الموحد وتسهيل الوصول للقضايا المشابهة.
  3. **مشاركة الكلمات المفتاحية:** إتاحة الكلمات المفتاحية في بطاقات القضايا ومشاركتها عبر منصة التقاضي.
* **حدود واستثناءات النطاق (Out of Scope):** 
  * تقتصر الخدمة على استخراج الكلمات المفتاحية والوسوم لدعم البحث والتكشيف والربط الموضوعي.
  * يُستثنى صراحة إجراء التوليد الصياغي لمسودات المذكرات أو التصنيف الموضوعي للهيكل القضائي.

## 3. قواعد العمل التشغيلية والاستخراجية (Extracted Business Rules)

1. **قاعدة استخراج الكلمات الجوهرية:** التعرف التلقائي على المصطلحات الإجرائية (مثل "عدم اختصاص"، "فوات ميعاد") والموضوعية (مثل "إنهاء خدمة"، "عقد توريد") المذكورة بنصوص القضية.
2. **قاعدة ترتيب الأهمية (`Relevance Ranking`):** احتساب درجة الأهمية لكل كلمة مفتاحية مستخرجة بناءً على سياقها القانوني وتكرارها التكشيفي.
3. **قاعدة مشاركة الوسوم:** عرض الوسوم المستخرجة في رأس بطاقة القضية وإتاحة النقر عليها لاستعراض القضايا المرتبطة موضوعياً.

## 4. نماذج البيانات المفككة (Dev-Ready Anonymized JSON Schemas)

### 📥 نموذج الطلب البرمجي (Input Request Schema):
```json
{
  "case_id": "LIT-XXXX-XXXX",
  "confidentiality_level": "RESTRICTED",
  "keyword_request": {
    "target_text": "[نصوص مستندات وصحف ومذكرات القضية المدخلة]",
    "max_keywords": 8
  },
  "user_context": {
    "user_id": "USR-XXXX",
    "role": "SYSTEM_SEARCH_ENGINE"
  }
}
```

```json
{
  "extraction_id": "KW-XXXX-001",
  "case_id": "LIT-XXXX-XXXX",
  "keywords": [
    {

      "keyword": "[المصطلح القانوني أو الكلمة المفتاحية 2]",
```
