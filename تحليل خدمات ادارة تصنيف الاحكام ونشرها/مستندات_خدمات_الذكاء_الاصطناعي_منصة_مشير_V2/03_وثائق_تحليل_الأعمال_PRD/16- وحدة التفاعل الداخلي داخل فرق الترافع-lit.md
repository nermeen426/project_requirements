## **وحدة التفاعل الداخلي داخل فرق التقاضي** 

### **1\. الغلاف**

* **اسم الوحدة:** التفاعل الداخلي داخل فرق التقاضي   
* **الجهة:** المكتب الفني – ديوان المظالم  
* **عنوان الوثيقة:** تحليل متطلبات وحدة التفاعل الداخلي داخل الفرق القضائية  
* **التاريخ السابق:** 06-08-2025  
* **الإصدار السابق:** 0.1 – مبدئي  
* **التاريخ الجديد:** 09-09-2025  
* **الإصدار الجديد:** 0.2 – نهائي

### **2\. المقدمة**

تهدف هذه الوثيقة إلى تحليل وحدة التفاعل الداخلي التي تُستخدم داخل نظام إدارة التقاضي لدعم المرونة والتواصل العملي بين أعضاء الفريق القضائي (دارس، مشارك، معتمد، ممثل...).  
 تُستخدم هذه الوحدة كآلية تفاعلية لتنفيذ المهام ومتابعتها داخل القضية الواحدة، مع الحفاظ على الحوكمة وسجل التوثيق، دون الإخلال بمسار القضية القضائي، وتسمح بالتعديل في الفريق، تمرير المهام، وتسجيل الملاحظات.

### **3\. الأهداف**

1. تمكين فرق العمل من التفاعل بمرونة دون الخروج عن المسار القضائي.  
2. دعم التمرير غير المتسلسل للمهام في الوضع الاسترشادي.  
3. دعم تعديلات الفريق أثناء سير القضية مع تسجيل كامل.  
4. تسهيل تبادل الملاحظات والمهام الإضافية بين أعضاء الفريق.  
5. ضمان استمرار العمل في حالات الغياب أو الإجازات.  
6. حفظ سجل دقيق لكل تفاعل بين أعضاء الفريق.

### **4\. الأدوار والصلاحيات**

| الدور | الوصف | الصلاحيات |
| ----: | ----: | ----: |
| مشرف إدارة التقاضي  | يحدد نمط التفاعل (إجباري/استرشادي) | ضبط إعدادات المسارات – متابعة سجل التفاعل |
| أعضاء الفريق (دارس – مشارك – معتمد – ممثل) | مستخدمين للوحدة حسب الدور | التفاعل، تمرير المهام، تعديل التواريخ، إضافة ملاحظات |
| النظام | إدارة سجلات التفاعل | تسجيل الأحداث، تقييد الحالات الاستثنائية، حفظ الترتيب |

### **5\. المتطلبات الوظيفية (Functional Requirements)**

**أولًا: إعداد نمط التفاعل**

| الكود | المتطلب |
| ----: | ----: |
| F-1.1 | اختيار نمط المسار (تسلسلي – مرن) من إعدادات النظام |
| F-1.2 | تحديد المهام التي يُسمح فيها بالتفاعل المرن |
| F-1.3 | تفعيل أو تعطيل التمرير الحر لكل نوع قضية |

**ثانيًا: التمرير الداخلي للمهام**

| الكود | المتطلب |
| ----: | ----: |
| F-2.1 | تمرير المهام بين الأعضاء (مثل تمرير مسودة مذكرة لمراجع إضافي) |
| F-2.2 | دعم تمرير المهمة دون فقدان التسلسل عند العودة للوضع الأصلي |
| F-2.3 | تسجيل التمريرات جميعها في سجل زمني رسمي |

**ثالثًا: تعديلات الفريق**

| الكود | المتطلب |
| ----: | ----: |
| F-3.1 | إمكانية استبدال عضو من الفريق أثناء سير القضية |
| F-3.2 | دعم إدخال بديل مؤقت في حالات الإجازة |
| F-3.3 | تسجيل السبب، تاريخ التعديل، ومصدر التعديل (يدوي/تلقائي) |

**رابعًا: التفاعل النصي والملاحظات**

| الكود | المتطلب |
| ----: | ----: |
| F-4.1 | دعم الملاحظات التفاعلية على أي مكوّن داخل القضية (مذكرة، مرفق...) |
| F-4.2 | إمكانية الرد على الملاحظات وربطها بالمهمة الأصلية |
| F-4.3 | دعم @mention لأعضاء الفريق داخل الملاحظات لسهولة التواصل |

**خامسًا: سجل التفاعل الكامل**

| الكود | المتطلب |
| ----: | ----: |
| F-5.1 | سجل زمني يُسجل كل تفاعل: تمرير، تعليق، تعديل فريق، رفع مرفق |
| F-5.2 | إتاحة تصفية السجل حسب المستخدم أو النوع أو التاريخ |
| F-5.3 | دعم تصدير السجل لأغراض التدقيق أو التوثيق الداخلي |

### **6\. المتطلبات غير الوظيفية (Non-Functional Requirements)**

| الكود | المتطلب |
| ----: | ----: |
| NFR-1 | سرعة فتح أي تفاعل أو ملاحظة خلال ثانيتين |
| NFR-2 | تكامل كامل مع مكونات القضية الأخرى (المذكرات، التواريخ، المشاركات...) |
| NFR-3 | إظهار الملاحظات فقط لأعضاء فريق القضية دون غيرهم |
| NFR-4 | دعم واجهة سهلة الاستخدام مع تصنيف التفاعلات حسب النوع |

### **7\. بعض حالات الاستخدام (Use Cases)**

**UC-1: تمرير مذكرة لمراجعة إضافية**

* المستخدم: دارس  
* الخطوات: فتح المذكرة → اختيار عضو → تمرير المهمة → تسجيل سبب التمرير  
* النتيجة: تم التمرير والمستخدم الآخر يتلقى إشعارًا

**UC-2: استبدال ممثل قانوني مؤقتًا**

* المستخدم: مشرف الإدارة  
* المدخلات: اسم الممثل الجديد، مدة التبديل  
* النتيجة: يظهر البديل في السجل، وتُحول المهام له تلقائيًا

**UC-3: إضافة ملاحظة على المرفق**

* المستخدم: مشارك  
* الخطوات: فتح المرفق → إضافة ملاحظة → ربطها بالمهمة  
* النتيجة: تُسجل الملاحظة وتظهر لبقية الفريق

### **8\. القيود والافتراضات**

**القيود:**

* لا يُسمح بالاطلاع على تفاعلات فريق آخر من عضو خارجي دون صلاحية.  
* التمرير لا يُغير من الصلاحيات الأصلية للأعضاء إلا إذا أُعطي تفويض.

**الافتراضات:**

* جميع القضايا تحتوي على فريق محدد مسبقًا بصلاحيات دقيقة.  
* نظام الإجازات متكامل مع النظام لتفعيل البدائل تلقائيًا عند الحاجة.
