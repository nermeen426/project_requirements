## **وحدة المشاركات الخارجية**

**1\. الغلاف**

* **اسم الوحدة:** المشاركات الخارجية  
* **الجهة:** المكتب الفني – ديوان المظالم  
* **عنوان الوثيقة:** تحليل متطلبات وحدة المشاركات الخارجية  
* **التاريخ السابق:** 06-08-2025  
* **الإصدار السابق:** 0.1 – مبدئي  
* **التاريخ الجديد:** 09-09-2025  
* **الإصدار الجديد:** 0.2 – نهائي

**2\. المقدمة**  
 تهدف هذه الوثيقة إلى تحليل المتطلبات الخاصة بوحدة المشاركات الخارجية، وهي وحدة موحدة تُستخدم للتواصل الرسمي بين إدارات المكتب الفني المختلفة وبين الإدارات الأخرى داخل ديوان المظالم، لدعم سير المعاملات المرتبطة (مثل: القضايا، الدراسات، المهام التنظيمية).  
 تُستخدم الوحدة ضمن نظام المكتب الفني الشامل، وترتبط بوحدات بكامل الوحدات والأنظمة الفرعية داخل نظام المكتب الفني.

**3\. الأهداف**

1. تمكين إدارات المكتب من طلب مستندات أو إفادات من إدارات أخرى داخل الديوان بطريقة رسمية وآمنة.  
2. توثيق كل تبادل رسمي بين الإدارات المرتبط بمعاملة محددة داخل النظام.  
3. التحكم في ما يتم مشاركته مع الجهة المستلمة حسب الصلاحيات.  
4. دعم خاصية الردود الإلحاقية وإعادة فتح المشاركة عند الحاجة.  
5. توفير سجل إشعارات دقيق ومتكامل لكل مشاركة.  
6. دعم التوسّع المستقبلي لربط المشاركات بوحدات الدراسات والقضايا وغيرها.

**4\. الأدوار والصلاحيات**

| الدور | الوصف | الصلاحيات |
| ----: | ----: | ----: |
| رئيس المكتب | إشراف كامل على المشاركات الخارجية | إنشاء – تعديل – الاطلاع على جميع المشاركات \- قبول أو رفض طلبات المشاركة \- تفويض صلاحية القبول والرفض |
| مشرف الإدارة | اعتماد الطلبات في حال له الصلاحية وإدارة مشاركات إدارته | نفس صلاحيات رئيس المكتب ضمن حدود إدارته وصلاحياته |
| عضو الإدارة | مستخدم فعّال لإنشاء المشاركات بعد التفويض | إنشاء طلب مشاركة – متابعة الردود – طلب رد إلحاقي |
| المستخدم الخارجي | الجهة المستلمة (داخل الديوان) | الاطلاع على ما يُسمح له به – الرد على المشاركة |

**5\. المتطلبات الوظيفية (Functional Requirements)**

**أولًا: إنشاء المشاركة**

| الكود | المتطلب |
| ----: | ----: |
| F-1.1 | إمكانية إنشاء طلب مشاركة جديدة مرتبطة بمعاملة محددة أو حرة |
| F-1.2 | تحديد نوع المشاركة (طلب مستند، طلب مرئيات، إفادة...) |
| F-1.3 | اختيار الجهات أو المستخدمين المستلمين من قائمة داخلية |
| F-1.4 | كتابة الملاحظات وإرفاق الملفات بشكل منفصل عن المعاملة |
| F-1.5 | اختيار ما يُعرض للأطراف الخارجية من بيانات |

**ثانيًا: الردود والمتابعة**

| الكود | المتطلب |
| ----: | ----: |
| F-2.1 | تسجيل الردود من الأطراف الخارجية داخل النظام |
| F-2.2 | امكانية طلب رد إلحاقي بعد الرد الأول |
| F-2.3 | إمكانية إعادة فتح المشاركة بطلب جديد |
| F-2.4 | تتبع حالة المشاركة (بانتظار الرد – تم الرد) |

**ثالثًا: الربط بالمعاملات**

| الكود | المتطلب |
| ----: | ----: |
| F-3.1 | ربط المشاركة تلقائيًا بالمعاملة عند الإنشاء من داخلها |
| F-3.2 | إتاحة ربط المشاركة يدويًا بمعاملة لاحقًا إن كانت حرة |
| F-3.3 | إظهار رقم المعاملة للأطراف الخارجية في حال كانت المشاركة مربوطة بمعاملة واردة من نظام الاتصالات الإدارية. |

**رابعًا: صلاحيات الاطلاع**

| الكود | المتطلب |
| ----: | ----: |
| F-4.1 | إعداد صلاحيات افتراضية حسب نوع المعاملة (قضية، دراسة...) |
| F-4.2 | تخصيص صلاحيات الاطلاع لكل مشاركة على حدة |
| F-4.3 | منع مشاركة النقاشات الداخلية أو التعليقات أو المهام الداخلية مع الطرف الخارجي |

**خامسًا: الإشعارات وسجل التتبع**

| الكود | المتطلب |
| ----: | ----: |
| F-5.1 | إرسال إشعار للأطراف المستلمة عند إنشاء المشاركة |
| F-5.2 | إرسال تذكير تلقائي او يدوي بعد فترة عدم الرد |
| F-5.3 | سجل إشعارات لكل مشاركة يشمل النوع، الوقت، الجهة، حالة الإرسال |

**سادسًا: التوثيق والمتابعة**

| الكود | المتطلب |
| ----: | ----: |
| F-6.1 | سجل زمني متكامل لكل إجراء على المشاركة |
| F-6.2 | حفظ الجهة المنشئة، محتوى المشاركة، الردود، التعديلات |
| F-6.3 | دعم تصدير سجل المشاركة والتفاعل كـ Excel – PDF \- Dashboardعند الحاجة |

**7\. بعض حالات الاستخدام (Use Cases)**

**UC-1: إنشاء طلب مشاركة مرتبطة بقضية**

* المستخدم: دارس أو ممثل مفوض  
* المدخلات: الجهة، نوع المشاركة، الملاحظات، المرفقات  
* النتيجة: إرسال طلب المشاركة لرئيس المكتب أو المفوض عنه المشاركة وتوثيقها وربطها بالقضية

**UC-2: الرد على مشاركة**

* المستخدم: الجهة المستلمة  
* المدخلات: محتوى الرد، مرفقات إضافية  
* النتيجة: تسجيل الرد وتحديث حالة المشاركة

**UC-3: إرسال تذكير يدوي**

* المستخدم: منشئ المشاركة أو رئيس المكتب  
* المدخلات: رقم المشاركة  
* النتيجة: إرسال إشعار يدوي للطرف الخارجي

**UC-4: إعادة فتح مشاركة**

* المستخدم: فريق العمل الداخلي  
* المدخلات: سبب الإعادة، درجة المعالجة الجديدة  
* النتيجة: استئناف المشاركة مع تحديث الحالة

**8\. القيود والافتراضات**

**القيود:**

* لا يُسمح بتعديل المشاركة بعد إرسالها.  
* لا يمكن للمستخدم غير المفوض إنشاء مشاركة.  
* لا يمكن إرسال طلب المشاركة إلا باعتماد رئيس المكتب او من هو مفوض عنه

**الافتراضات:**

* جميع المستخدمين الخارجيين داخل الديوان.
